# Exercise 3: Conflict Resolution

 1. Create two branches from main
git checkout main
git pull origin main
git checkout -b branchA
git checkout main
git checkout -b branchB

2. Modify the same line in a file in both branches
On branchA
git checkout branchA
echo "Hello from branch A" > example.txt
git add example.txt
git commit -m "Update line in example.txt from branchA"
On branchB
git checkout branchB
echo "Hello from branch B" > example.txt
git add example.txt
git commit -m "Update line in example.txt from branchB"
 3. Merge branchA into main
git checkout main
git merge branchA

4. Attempt to merge branchB (this will cause a conflict)
git merge branchB

 5. Resolve the conflict manually
Open example.txt and edit it to resolve conflict, e.g.:
Hello from branch A
 Hello from branch B
Then mark resolved:
git add example.txt
git commit -m "Resolve merge conflict between branchA and branchB"
